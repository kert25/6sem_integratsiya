# Чек-лист интеграционного тестирования

## Сервис пользователей
- [ ] POST /register с корректными данными → 201 Created
- [ ] POST /register с существующим email → 409 Conflict
- [ ] POST /login с верными учетными данными → 200 + токен
- [ ] POST /login с неверными данными → 401 Unauthorized
- [ ] GET /users/{id} с валидным токеном → 200 + данные пользователя
- [ ] GET /users/{id} без токена → 401 Unauthorized

## Интеграционные сценарии
- [ ] Создание заказа с авторизацией → успех
- [ ] Создание заказа без авторизации → ошибка
- [ ] Оплата заказа → уменьшение остатков товара
- [ ] Создание заказа при недостаточном остатке → ошибка
