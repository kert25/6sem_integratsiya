Инструменты проекта `_tools\` (проверены 29.09.2026):
- `make_docx.py` — сборка отчёта: `py _tools\make_docx.py --out <ЛРN\Отчет_ЛРN.docx> --num N --theme "<тема>" --content <content.json>`; элементы контента `{"h"|"p"|"code"|"codefile"|"img"+"caption"|"pb"}` и `{"table": {"rows": [[...]], "widths": [dxa], "header": true}}` (таблицы с одинарными границами, полужирная шапка с заливкой, `cantSplit` строк, "\n" в ячейке — новый абзац; ширины в dxa, полезная ширина 9355); титульник адаптирован под дисциплину и Басалова Ю.А.
- `build_report.py` — канонический раннер сборки: `py _tools\build_report.py <корень_проекта> <N>`; темы (кириллица) — в THEMES внутри файла, командная строка остаётся ASCII; читает `ЛРN\content.json` → `ЛРN\Отчет_ЛРN.docx`.
- `inspect_docx.py <файл.docx> [N]` — дамп структуры docx (абзацы + таблицы TBL/TR).
- `docx2pdf.py <in.docx> <out.pdf>` — конвертация через MS Word COM (требуется pywin32 — установлен 29.09.2026).
- `pdftext.py <in.pdf>` — постраничный текст PDF (pymupdf — установлен 29.09.2026).
- `extract_docx.py <N>` — выгрузка текста методички из папки ЛРN (docx → word/document.xml → regex); альтернативно `<путь.docx>` (ASCII). Проверен 29.09.2026 на методичке ЛР3.
- `run_pytest.py <N> [-- <аргументы>]` — запуск pytest в папке ЛРN (кириллический путь собирается внутри; по умолчанию `-v --tb=line`). Для чистого вывода в файл: `$env:PYTHONUTF8='1'` + `-- --tb=no`.
- Конвейер верификации отчёта: `build_report.py` → `docx2pdf.py` → `pdftext.py` (текстовый дамп: пустые страницы, порядок разделов, содержимое таблиц; LibreOffice/poppler в системе нет, Word есть; картинки/PDF как вложения в этой среде не читаются — только текст).
- `_tools\gui\` — автономные хелперы для GUI-автоматизации (проверены на Postman 29.09.2026): `ss_ocr.ps1 -App "<заголовок окна>" -Path <png>` (скриншот + WinRT OCR en-US → JSON слов с координатами), `ss_click.ps1 X Y [-Dbl]`, `ss_key.ps1 "<SendKeys>"`, `ss_paste.ps1 "<текст>"` (через буфер — для кириллицы), `run_request.ps1 <x> <y> "<имя>"` (клик по запросу в сайдбаре → Send → OCR статуса и тестов), `crop_ocr.py`, `pngcheck.py` (валидация размеров PNG). Координаты — абсолютные (окно максимизировано); позиции кнопок вроде Send плавают — искать через OCR по тексту. Скриншоты читать не умеем — только OCR/факт наличия.

Повторная выгрузка текстов методичек при необходимости: py-скрипт (zipfile → word/document.xml → regex; `</w:tc>`→" | ", `</w:tr>`→"\n"). Репо преподавателя: `git clone https://github.com/basalovyurij/course-integration-and-testing-of-software-systems-examples`.
